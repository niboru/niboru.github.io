================================================================
WHY SOME SCREENS FEEL MUCH HARSHER THAN OTHERS
VERSION 2 — SIMPLE DISPLAY SCIENCE GUIDE
================================================================

PURPOSE

A screen can cause visual discomfort for reasons that have nothing to do with obvious flicker.

The important variables are PWM, temporal dithering, pixel response, brightness, contrast, spectrum, surface coating, spatial sharpness, motion, viewing distance, and room lighting.

These variables can interact, but they should be investigated separately.

The goal is not to prove that modern displays are bad, but to understand why two technically functional displays can feel very different.


================================================================
1. THE BIG ILLUSION: A SCREEN IS NOT A STATIC PRINTED PAGE
================================================================

A printed page normally reflects light from the room toward your eyes.

A display produces light itself and sends that light directly toward your eyes.

A screen can therefore look completely still while its light output or pixel values are changing over time.

The visual system receives the FINAL LIGHT OUTPUT, not the manufacturer's specification sheet.

This is why display comfort is ultimately a question of what reaches the eye.


================================================================
2. THE MAIN DISPLAY VARIABLES
================================================================

PWM changes brightness by changing light output over time.

FRC, or temporal dithering, changes pixel values over time to create additional apparent shades.

Pixel response determines how quickly a physical pixel can follow a requested change.

Brightness determines how much light enters the eye.

Contrast determines how strongly neighboring light and dark regions differ.

Color spectrum determines which wavelengths of light are being emitted.

Surface coating changes how ambient light interacts with the screen surface.

Spatial sharpness determines how abruptly brightness changes at text and object edges.

Motion determines how much visual tracking is required when information moves.

Viewing distance and room lighting change the optical conditions under which all of these mechanisms are experienced.


================================================================
3. PWM: THE FIRST TEMPORAL MECHANISM
================================================================

PWM means Pulse-Width Modulation.

A PWM display can control brightness by rapidly switching its light source between ON and OFF states.

A simplified PWM sequence might look like:

    ON → ON → OFF → ON → ON → OFF

The eye can perceive this as a steady intermediate brightness when the switching is sufficiently rapid.

Lowering brightness on a PWM display can therefore mean increasing the proportion of time that the light is OFF rather than continuously producing weaker light.

PWM frequency, modulation depth, waveform, brightness level, and individual sensitivity all influence how noticeable the modulation is.

A person does not necessarily have to consciously see flicker for a display to feel uncomfortable.

Invisible flicker is therefore a possible source of visual discomfort, not proof that every invisible flicker is harmful.


================================================================
4. FRC: THE SECOND TEMPORAL MECHANISM
================================================================

FRC means Frame Rate Control.

FRC can create an intermediate shade by rapidly alternating between nearby shades that the physical panel cannot directly reproduce.

A simplified example is:

    DARK GRAY → LIGHT GRAY → DARK GRAY → LIGHT GRAY

The visual system can integrate these rapidly changing values and perceive an intermediate gray.

FRC is mainly a COLOR-DEPTH TECHNIQUE, whereas PWM is mainly a BRIGHTNESS-CONTROL TECHNIQUE.

A display can therefore have PWM without FRC, FRC without significant PWM, both, or neither.


================================================================
5. WHY DISPLAYS USE FRC
================================================================

Producing more native brightness and color levels can increase panel and electronics cost.

A lower-bit panel can use temporal or spatial techniques to produce more apparent shades.

A 6-bit panel has 64 physical levels per color channel.

An 8-bit channel has 256 physical levels per color channel.

Native 8-bit RGB provides approximately 16.7 million possible RGB combinations.

An 8-bit + 2-bit FRC system can produce an apparent color range beyond what its physical 8-bit states alone provide.

A specification such as “10-bit” therefore does not automatically mean every physical pixel has native 10-bit control.


================================================================
6. PWM AND FRC MUST NOT BE CONFUSED
================================================================

PWM primarily asks:

    HOW MUCH LIGHT SHOULD THE DISPLAY PRODUCE?

FRC primarily asks:

    WHICH INTERMEDIATE COLOR OR BRIGHTNESS LEVEL SHOULD THE PIXEL APPEAR TO PRODUCE?

PWM operates mainly at the light-output level.

FRC operates mainly at the pixel-value or color-level.

Both can produce temporal changes, but they are different mechanisms.


================================================================
7. PIXEL RESPONSE TIME CHANGES THE RESULT
================================================================

Pixel response time describes how quickly a pixel changes from one state to another.

Older LCD panels commonly had slower transitions than modern fast LCDs and OLED displays.

A slow pixel cannot follow a rapidly changing signal perfectly.

A slow transition spreads the change across more time and can therefore make temporal changes appear less sharp.

A fast pixel follows the requested change more quickly and can preserve more of the temporal structure.

This means pixel speed can CHANGE HOW TEMPORAL MODULATION APPEARS.

Slow response does NOT mean that FRC disappears.

Fast response does NOT mean that FRC automatically becomes harmful.


================================================================
8. THE OLD LCD "PHYSICAL BLUR" IDEA
================================================================

Older LCDs often had response times around tens of milliseconds.

Their slow liquid-crystal movement produced visible motion blur and ghosting.

That physical response can also reduce the sharpness of some rapidly changing pixel-level signals.

This can make a temporal artifact appear more spread out rather than sharply defined.

It is more accurate to call this TEMPORAL SMOOTHING than to claim that old LCDs simply eliminated FRC.

The same slow response that may soften temporal changes also creates motion blur.


================================================================
9. WHY EXTREMELY SLOW DISPLAYS ARE NOT THE ANSWER
================================================================

Very slow pixels can leave trails behind moving objects.

Scrolling text can become blurred and smeared.

The visual system then has to track less clearly defined moving shapes.

This can create a different type of visual workload.

The practical goal is therefore NOT:

    MAKE THE PIXELS AS SLOW AS POSSIBLE.

The practical goal is:

    ENOUGH RESPONSE SPEED FOR CLEAR MOTION WITHOUT INTRODUCING AN UNCOMFORTABLE TEMPORAL CHARACTER.


================================================================
10. THE DISPLAY PIPELINE
================================================================

A modern display can be represented as:

    APPLICATION
        ↓
    OPERATING SYSTEM / COMPOSITOR
        ↓
    GPU / DISPLAY ENGINE
        ↓
    DISPLAY INTERFACE
        ↓
    DISPLAY CONTROLLER / TCON / DDIC
        ↓
    PIXELS
        ↓
    LIGHT
        ↓
    EYES
        ↓
    VISUAL SYSTEM

Color processing or dithering can occur at different stages depending on the particular device.

Operating systems do not automatically dither every frame.

GPU drivers do not automatically dither every frame.

Display driver ICs do not automatically use FRC for every displayed color.

The correct model is that DITHERING CAN OCCUR AT MULTIPLE STAGES, not that everything is always dithering.


================================================================
11. THE SMARTPHONE DITHERING HISTORY
================================================================

Early mobile LCDs sometimes used lower-bit panels because native high-bit display hardware was expensive and power-hungry.

Display-driver electronics could use spatial or temporal techniques to produce more apparent colors.

Modern smartphone display pipelines became increasingly sophisticated as operating systems added transparency, gradients, shadows, HDR, and wide-gamut color.

OLED introduced another challenge because extremely dark brightness levels are difficult to control perfectly.

Display electronics can use temporal techniques to make low-level shades appear smoother.

Modern HDR pipelines can also require additional processing when the requested color depth exceeds the panel's native physical capability.

The exact location and behavior of dithering depend on the specific phone, panel, driver, operating system, and content.


================================================================
12. WHY TWO FRC DISPLAYS CAN LOOK COMPLETELY DIFFERENT
================================================================

Two phones can both use FRC and still produce different visual experiences.

Their temporal frequency can differ.

Their modulation depth can differ.

Their subpixel arrangement can differ.

Their panel response can differ.

Their brightness-control method can differ.

Their color-processing pipeline can differ.

Their low-gray processing can differ.

Therefore:

    BOTH USE FRC

does NOT mean:

    BOTH HAVE THE SAME TEMPORAL BEHAVIOR.


================================================================
13. GRADIENT SMOOTHNESS IS NOT TEMPORAL STABILITY
================================================================

A smooth gradient does not prove that a display is temporally stable.

A display can make a gradient smoother by using dithering.

A display can show slight banding while using less temporal interpolation.

Therefore gradient appearance answers:

    HOW SMOOTH DOES THE GRADIENT LOOK?

Temporal testing asks:

    DOES AN APPARENTLY FIXED COLOR ACTUALLY STAY PHYSICALLY STABLE?

For FRC testing, temporal behavior is the more important question.


================================================================
14. WHAT TEMPORAL DITHERING LOOKS LIKE IN PRINCIPLE
================================================================

A temporally stable pixel might behave like:

    GRAY
    GRAY
    GRAY
    GRAY

A temporally dithered pixel might behave like:

    DARKER
    LIGHTER
    DARKER
    LIGHTER

The viewer may perceive both as approximately the same gray.

The important difference is that one physical output remains stable while the other changes over time.

Possible visible clues include shimmer, crawling grain, unstable texture, or subtle movement in apparently fixed dark colors.

These clues are useful for testing but are not by themselves proof of a specific hardware implementation.


================================================================
15. THE THIRD MAJOR VARIABLE: BRIGHTNESS
================================================================

A temporally stable display can still be uncomfortable if it is excessively bright.

Brightness increases the amount of light entering the eye.

A bright screen can feel particularly harsh when the surrounding room is dark.

The same display can therefore feel different after the room lighting changes.

Brightness should be tested independently from PWM and FRC.


================================================================
16. CONTRAST IS A DIFFERENT VARIABLE AGAIN
================================================================

Contrast describes the difference between light and dark areas.

White text on a black background produces a very strong local luminance transition.

Strong transitions make edges extremely easy to detect.

High contrast is useful for readability but can feel visually harsh to some people.

High contrast therefore does not automatically mean better comfort.


================================================================
17. DARK MODE IS NOT AUTOMATICALLY EASIER
================================================================

Dark mode can reduce overall screen brightness in some situations.

Dark mode can also create extremely strong local contrast when bright white text is placed on pure black.

Some OLED displays additionally use specialized low-level processing around near-black shades.

That processing can include temporal modulation depending on the particular panel and driver.

A person sensitive to temporal artifacts may therefore notice grain, shimmer, or crawling texture in dark areas.

Dark mode should therefore be evaluated by the actual display behavior rather than assumed to be universally easier.


================================================================
18. OLED: A SPECIAL CASE
================================================================

OLED pixels generate their own light.

OLED can therefore produce extremely deep blacks by reducing or eliminating light from individual pixels.

OLED pixels can also change state extremely quickly.

Very low OLED brightness levels are technically difficult because the relationship between electrical drive and visible light is not perfectly simple near black.

Display electronics may use additional processing or temporal techniques to make these low-level shades appear smoother.

This is one reason that OLED behavior at low brightness can differ substantially between models.


================================================================
19. W-LED: THE MODERN LCD BACKLIGHT
================================================================

W-LED means WHITE LED.

Many modern LCD monitors and laptops use white LEDs as their backlight source.

A common W-LED design starts with a blue LED and uses a phosphor layer to convert part of that blue emission into broader longer-wavelength light.

This produces a combined spectrum that the eye interprets as white.

The resulting spectrum is NOT identical to the spectrum of an older CCFL backlight.

Different W-LED implementations can also have different spectral shapes.


================================================================
20. W-LED VS CCFL
================================================================

Older CCFL LCDs commonly used fluorescent lamps with phosphor mixtures that produced broader spectral output.

Many modern W-LED systems have a more pronounced blue emission peak.

A commonly used blue-pump W-LED design has a strong emission region around the blue wavelengths.

The exact spectrum varies by LED and phosphor design, so a specific monitor should be measured rather than judged solely from the term W-LED.

W-LED itself does NOT mean that a display is harmful.

It means the backlight uses white LED technology.


================================================================
21. BLUE LIGHT AND CHROMATIC ABERRATION
================================================================

Blue light has shorter wavelengths than green or red light.

Shorter wavelengths interact differently with the optical system of the eye.

The eye exhibits LONGITUDINAL CHROMATIC ABERRATION, meaning different wavelengths are not focused at exactly the same distance.

This means blue and red portions of an image can have slightly different focal positions.

The effect is part of normal human optics.

It becomes more relevant when a display contains strong short-wavelength emission together with high brightness and fine high-contrast detail.

It is NOT established that ordinary W-LED viewing automatically forces the ciliary muscle into harmful continuous contraction.

A more defensible conclusion is that spectral composition can influence visual quality and comfort, particularly when brightness and contrast are also high.


================================================================
22. BLUE LIGHT IS NOT THE SAME AS SCREEN FLICKER
================================================================

Blue-light exposure and temporal flicker are separate physical properties.

A display can have:

    LOW BLUE OUTPUT + PWM

or:

    HIGH BLUE OUTPUT + DC DIMMING

or:

    LOW BLUE OUTPUT + LOW TEMPORAL MODULATION

Therefore reducing blue light does not automatically solve a PWM problem.

Removing PWM does not automatically solve a spectral problem.


================================================================
23. HARDWARE LOW-BLUE-LIGHT MODES
================================================================

Some displays use LEDs or optical filters designed to reduce short-wavelength output.

Other displays reduce blue content through software color adjustment.

Hardware approaches can alter the emitted spectrum itself.

Software night modes mainly change the displayed RGB values.

A certification can provide useful information about the tested spectral output, but the exact certification criteria should be checked rather than treating every "low blue light" label as equivalent.


================================================================
24. COLOR TEMPERATURE
================================================================

A cooler display generally contains relatively more blue-looking light.

A warmer display shifts the visual balance toward yellow and red.

A setting around 5000–6500 K can produce a warmer appearance than a very cool factory setting.

Color temperature is a visual description of spectral balance, not a direct measurement of total blue-light hazard.

A warm software tint also does not prove that the physical backlight has changed its emission spectrum.


================================================================
25. THE FOURTH VARIABLE: SURFACE COATING
================================================================

The screen surface affects how light is scattered before reaching your eyes.

A glossy surface reflects more distinct images of surrounding light sources.

A matte anti-glare surface spreads reflected light over a wider area.

Anti-glare treatment can therefore reduce obvious reflections.

But strong surface diffusion can introduce another visual effect commonly called AG SPARKLE.


================================================================
26. AG SPARKLE
================================================================

AG means ANTI-GLARE.

A strongly textured matte coating contains microscopic variations in its surface.

Light passing through or reflecting from these microscopic structures can be scattered unevenly.

The result can be a fine grain or sparkle over the image.

This can be especially noticeable on white backgrounds and fine text.

The effect can make a smooth digital image look more like a textured physical surface.


================================================================
27. THE "PAPER" OR "PAINT" EFFECT
================================================================

A strong matte coating can make a display appear less optically clean.

Instead of seeing:

    CLEAN PIXEL → CLEAN PIXEL → CLEAN PIXEL

you may perceive:

    PIXEL + SURFACE GRAIN + SCATTERED LIGHT

The image can therefore feel like it has a very fine paper or paint texture.

This is sometimes described as the CRYSTALLINE EFFECT.

The problem is not necessarily brightness or flicker; the surface itself can alter the perceived image.


================================================================
28. WHY AG SPARKLE CAN FEEL LIKE EXTRA VISUAL WORK
================================================================

The visual system normally tries to extract a clean image from the light entering the eye.

Fine surface texture adds additional spatial variation to that image.

When tiny surface variations overlap fine pixel structures, the eye may perceive unstable-looking grain or local brightness variation.

This can make text and uniform backgrounds look less clean.

The precise physiological mechanism behind this discomfort is less certain than the basic optical effect itself.

Therefore AG sparkle should be treated primarily as an OPTICAL IMAGE-QUALITY ISSUE that can contribute to visual fatigue in susceptible users.


================================================================
29. GLOSSY VS MATTE IS A TRADE-OFF
================================================================

Glossy surfaces can provide a cleaner-looking pixel image when reflections are controlled.

Glossy surfaces can become uncomfortable when they reflect windows, lamps, or bright room objects.

Matte surfaces suppress those obvious reflections.

Strong matte surfaces can instead introduce AG sparkle.

A practical choice therefore depends on which optical problem is actually present in the room.


================================================================
30. INK-LIKE DISPLAY APPEARANCE
================================================================

INK-LIKE means that text and graphics appear visually calm, solid, and naturally integrated rather than glowing or aggressively outlined.

An ink-like appearance is NOT produced by one specification.

It is the combined result of:

    suitable brightness
    moderate local contrast
    clean surface treatment
    stable pixels
    appropriate gamma
    good text rendering
    controlled spectral output
    sufficient but not excessive sharpness

A display can therefore be technically sharp while still looking harsh.

A display can also be slightly softer while appearing more natural and paper-like.


================================================================
31. WHY OLDER DISPLAYS CAN SOMETIMES LOOK MORE "INK-LIKE"
================================================================

Older TN and CCFL displays often had softer optical and tonal characteristics.

Their viewing-angle-dependent gamma could cause brightness and contrast to change across the screen.

Their slower pixels produced more motion blur.

Their CCFL backlights often had different spectral characteristics from modern W-LED systems.

Some users therefore perceive certain older displays as softer, calmer, or more ink-like.

This does NOT mean that all older displays were objectively easier on the eyes.

It means their combination of optical characteristics can produce a different visual presentation.


================================================================
32. TN GAMMA AND VIEWING ANGLE
================================================================

TN means TWISTED NEMATIC.

TN panels historically tend to show stronger viewing-angle-dependent changes in brightness and gamma than IPS.

As the viewing angle changes, the apparent tone of a pixel can change.

This can soften or alter luminance transitions across the image.

That characteristic can contribute to an older display's softer visual appearance.

It can also reduce image consistency and color accuracy.

Therefore the "softness" of TN should not automatically be interpreted as superior image quality.


================================================================
33. IPS AND LOCAL EDGE CONTRAST
================================================================

IPS means IN-PLANE SWITCHING.

Modern IPS displays can produce clean, consistent pixel transitions and sharp text.

A sharp transition such as:

    WHITE TEXT
        ↓
    BLACK BACKGROUND

contains a strong local luminance boundary.

The retina contains mechanisms that emphasize changes at edges.

This can make already-sharp boundaries appear particularly crisp.

The phenomenon is related to LATERAL INHIBITION and can contribute to perceived edge enhancement such as Mach-band effects.


================================================================
34. MACH BANDS
================================================================

Mach bands are a perceptual effect in which the visual system exaggerates brightness differences near boundaries.

The eye is designed to detect edges efficiently.

A high-contrast display can therefore produce edges that feel exceptionally pronounced.

This does not mean that the retina is being physically damaged by the edge.

It means the visual system is responding strongly to a high-contrast spatial transition.


================================================================
35. WHY "INK-LIKE" CAN FEEL DIFFERENT FROM "ULTRA-SHARP"
================================================================

Ultra-sharp text maximizes edge definition.

Ink-like text aims for a clean edge without making the entire image feel excessively luminous or aggressive.

A display can therefore be:

    SHARP + HARSH

or:

    SHARP + CALM

depending on brightness, contrast, gamma, coating, spectrum, rendering, and viewing conditions.

The goal is not to make text blurry.

The goal is to avoid unnecessary visual harshness while retaining sufficient clarity.


================================================================
36. CONTRAST RATIO VS LOCAL CONTRAST
================================================================

Static contrast ratio describes the difference between a display's dark and bright output under a measurement condition.

Local contrast describes the difference between neighboring areas of an actual image.

A monitor can have excellent static contrast while still displaying extremely strong local transitions.

Therefore a high contrast-ratio specification does not automatically predict visual comfort.


================================================================
37. IPS GLOW
================================================================

IPS LCDs can show brighter-looking regions when viewed off-axis, especially in dark scenes.

This is commonly called IPS GLOW.

It is a panel characteristic rather than the same thing as backlight brightness or PWM.

In a dark room, IPS glow can make black areas appear less uniformly black.

That can change the perceived contrast of dark-mode content.


================================================================
38. VA AS ANOTHER TRADE-OFF
================================================================

VA means VERTICAL ALIGNMENT.

VA LCDs commonly provide substantially higher native static contrast than ordinary IPS panels.

Higher native contrast can produce deeper blacks and less backlight glow.

VA panels can also have slower dark-to-dark transitions on some models.

Those slow transitions can produce BLACK SMEARING during scrolling.

Black smearing can create motion-related visual workload even when the display has little PWM.


================================================================
39. IPS VS VA FOR COMFORT
================================================================

IPS can provide cleaner motion and consistent viewing-angle behavior.

VA can provide deeper blacks and higher native contrast.

IPS can therefore be preferable for clean moving text for some users.

VA can provide a calmer dark background for some users.

Neither IPS nor VA can automatically be labeled as the more comfortable technology.

The actual panel implementation matters more than the category name alone.


================================================================
40. WHY MODERN DISPLAYS FEEL DIFFERENT FROM OLD DISPLAYS
================================================================

Modern displays are not simply old displays made brighter.

Modern panels commonly combine:

    faster pixel response
    higher refresh rates
    wider color gamut
    HDR
    sophisticated color processing
    LED or OLED light sources
    stronger contrast
    thinner optical stacks

Each improvement solves a particular engineering problem.

The combination also creates a more complex visual environment.


================================================================
41. THE IMPORTANT HISTORICAL TRADE-OFF
================================================================

Older displays often had:

    slower pixels
    more motion blur
    simpler color pipelines
    narrower gamut
    different backlights
    different surface coatings

Modern displays often have:

    faster pixels
    cleaner motion
    more complex color processing
    wider gamut
    higher brightness
    stronger contrast
    different spectral output

Therefore:

    OLD ≠ AUTOMATICALLY GOOD

and:

    NEW ≠ AUTOMATICALLY BAD.

The technologies simply move the trade-offs.


================================================================
42. WHY A "BETTER" SPECIFICATION CAN FEEL WORSE
================================================================

A faster panel can reduce ghosting while making temporal changes more sharply represented.

A brighter panel can make HDR highlights more impressive while increasing visual intensity.

A wider-gamut panel can reproduce more colors while producing a more saturated appearance.

A stronger anti-glare coating can reduce reflections while adding sparkle.

A higher-contrast panel can make blacks deeper while making white-on-black edges more pronounced.

A higher resolution can make text finer and clearer while requiring more precise visual accommodation.

This is why specifications must be interpreted as ENGINEERING FEATURES rather than comfort ratings.


================================================================
43. THE VISUAL SYSTEM
================================================================

The ciliary muscle changes the shape of the eye's lens to focus on objects.

The iris changes pupil size in response to light.

The retina converts incoming light into neural signals.

The visual brain processes brightness, color, movement, edges, and spatial patterns.

The trigeminal system carries sensory information from the eye and face.

The blink system maintains the tear film over the eye surface.

These systems can all contribute to what a person experiences as visual discomfort.


================================================================
44. ACCOMMODATION AND FOCUS
================================================================

Accommodation is the process of adjusting the eye's optical power to focus on a target.

Fine text requires the visual system to maintain accurate focus.

Small text, close viewing distance, high resolution, and strong edge contrast can increase the demand for precise visual processing.

Temporary difficulty shifting focus after prolonged near work can occur as part of ordinary visual fatigue.

This is different from claiming that screen flicker physically forces the ciliary muscle to contract hundreds of times per second.


================================================================
45. BLINKING AND DRY EYES
================================================================

People commonly blink less frequently or incompletely during concentrated screen work.

Fewer or less complete blinks allow the tear film to break up more quickly.

A disturbed tear film can cause:

    dryness
    burning
    stinging
    redness
    fluctuating clarity

Dry-eye symptoms can therefore occur even on a completely flicker-free display.

This is one reason that not every screen-related symptom should be blamed on PWM or FRC.


================================================================
46. VISUAL MOTION AND THE BRAIN
================================================================

The visual system is highly sensitive to movement.

Scrolling text creates continuous visual motion even when the body is stationary.

Poor pixel response can turn that movement into ghosting or smearing.

Rapid visual motion can cause discomfort or nausea in susceptible people.

This is a separate mechanism from static brightness, PWM, or FRC.


================================================================
47. WHY A STILL PAGE CAN SOMETIMES FEEL UNSTABLE
================================================================

A page can appear stationary while individual pixels or subpixels undergo temporal changes.

PWM can change overall light output.

FRC can change individual color or brightness levels.

Low-gray OLED processing can introduce additional temporal behavior.

The viewer may therefore perceive shimmer, grain, crawling, or instability even though the page itself is not moving.


================================================================
48. THE "STACKED LOAD" IDEA
================================================================

A person may be exposed to several visual demands simultaneously.

For example:

    PWM
        +
    FRC
        +
    high brightness
        +
    high contrast
        +
    fine text
        +
    glossy reflections
        +
    long viewing time

The individual factors do not have to be dangerous for their combination to feel uncomfortable.

This is why a display that passes one test can still feel bad in real-world use.


================================================================
49. WHY INDIVIDUAL EXPERIENCE MATTERS
================================================================

People differ in their sensitivity to flicker, motion, brightness, contrast, surface texture, and visual workload.

One person may comfortably use a display that another person quickly finds unpleasant.

A personal reaction is therefore useful evidence about PERSONAL COMFORT.

A personal reaction alone does not prove the exact physical mechanism responsible.

Controlled comparison is more informative than guessing from symptoms alone.


================================================================
50. HOW TO TEST A DISPLAY WITHOUT MIXING VARIABLES
================================================================

Use the same content when comparing two displays.

Keep viewing distance approximately equal.

Keep room lighting approximately equal.

Keep screen brightness approximately comparable.

Test static text separately from moving text.

Test brightness changes separately from color-mode changes.

Test temporal stability separately from gradient smoothness.

Change one variable at a time whenever possible.

A controlled comparison is more useful than changing five display settings simultaneously.


================================================================
51. TEST A — BRIGHTNESS
================================================================

Reduce brightness gradually while keeping other settings unchanged.

If discomfort changes substantially, brightness is likely an important variable.

Do not assume that lower brightness means lower temporal modulation.

Check whether the brightness-control method changes at different brightness levels.


================================================================
52. TEST B — PWM
================================================================

Investigate brightness modulation at several brightness settings.

A display can change its PWM behavior as brightness changes.

"Flicker-free" generally refers to brightness modulation and does not automatically prove that every form of temporal pixel modulation is absent.

PWM testing therefore answers one question rather than the entire display-comfort question.


================================================================
53. TEST C — FRC / TEMPORAL DITHERING
================================================================

Display controlled gradients and flat colors.

Look for:

    shimmer
    crawling grain
    unstable dark shades
    moving texture

Do not judge only by whether the gradient looks smooth.

The objective is to determine whether an apparently fixed color changes over time.


================================================================
54. TEST D — MOTION
================================================================

Scroll ordinary text.

Look for:

    ghosting
    trailing
    black smearing
    smeared letters
    difficulty following moving text

This measures a different problem from FRC.


================================================================
55. TEST E — STATIC TEXT
================================================================

Read normal text for an extended period.

Use realistic font sizes rather than only laboratory patterns.

Observe whether discomfort appears during ordinary work.

Real-world testing matters because the display is ultimately being used for real-world visual tasks.


================================================================
56. TEST F — SURFACE SPARKLE
================================================================

Display a large white or light-gray background.

Move your head slightly while looking at the screen.

Observe whether the surface produces visible grain or sparkle over otherwise uniform content.

Compare the same content on a glossy, semi-gloss, and strongly matte surface when possible.

This can reveal a coating problem that PWM testing cannot detect.


================================================================
57. TEST G — CONTRAST
================================================================

Compare:

    WHITE TEXT ON PURE BLACK

against:

    LIGHT GRAY TEXT ON DARK CHARCOAL

The second arrangement reduces the local luminance difference.

If the softer version is more comfortable, local contrast may be contributing to the experience.


================================================================
58. TEST H — SPECTRAL BALANCE
================================================================

Compare the default display mode with a warmer or hardware low-blue-light mode.

Keep brightness approximately equal during the comparison.

If the warmer mode feels different, spectral balance may be relevant.

Do not conclude from this test alone that blue light was the sole cause.


================================================================
59. THE "INK-LIKE" PRACTICAL TARGET
================================================================

A useful comfort target is:

    CLEAN TEXT
        +
    MODERATE BRIGHTNESS
        +
    CONTROLLED LOCAL CONTRAST
        +
    LOW DISTRACTING SURFACE SPARKLE
        +
    STABLE TEMPORAL OUTPUT
        +
    ADEQUATE PIXEL RESPONSE
        +
    NATURAL-LOOKING COLOR

This is what produces the practical feeling of a calm, ink-like image.

The objective is NOT maximum softness.

The objective is CLEAN INFORMATION WITHOUT UNNECESSARY VISUAL AGGRESSION.


================================================================
60. FLICKER-FREE DOES NOT MEAN FRC-FREE
================================================================

"Flicker-Free" generally addresses brightness modulation.

A display can be flicker-free and still use temporal dithering.

A display can therefore pass a PWM test and still show temporal pixel behavior.

This distinction is essential when diagnosing a display.


================================================================
61. NATIVE 8-BIT DOES NOT MEAN TEMPORALLY PERFECT
================================================================

Native 8-bit means the panel can directly represent 256 levels per color channel.

Native 8-bit reduces the need for FRC to create ordinary 8-bit shades.

Native 8-bit does not automatically eliminate PWM.

Native 8-bit does not automatically eliminate all temporal processing.

Therefore native bit depth and temporal stability are separate measurements.


================================================================
62. "10-BIT" DOES NOT AUTOMATICALLY MEAN NATIVE 10-BIT
================================================================

A display can accept or process a 10-bit signal without having native 10-bit physical output at every pixel.

8-bit + FRC can create additional apparent shades.

The specification should therefore distinguish between:

    NATIVE 10-BIT

and:

    8-BIT + FRC.


================================================================
63. HIGH REFRESH RATE DOES NOT AUTOMATICALLY SOLVE FLICKER
================================================================

Refresh rate describes how frequently the display updates frames.

PWM frequency is a separate parameter.

FRC frequency is another parameter.

A 120 Hz display can therefore still use PWM.

A 240 Hz display can still use temporal dithering.

Refresh rate alone cannot establish temporal stability.


================================================================
64. HIGH BRIGHTNESS DOES NOT AUTOMATICALLY MEAN BETTER IMAGE QUALITY
================================================================

High brightness helps HDR highlights remain visible in bright environments.

Excessive brightness can make ordinary desktop content unnecessarily intense.

The comfortable brightness is determined by the actual environment and viewer.

A screen should be bright enough for clear viewing without becoming the brightest object in the room unnecessarily.


================================================================
65. VIEWING DISTANCE
================================================================

The closer a screen is, the larger it appears to the visual system.

Small text becomes more demanding when viewed very close.

A practical starting point for phones is roughly 35–40 cm when comfortable and readable.

A practical starting point for larger displays is commonly around arm's length, adjusted for text size and personal comfort.

Distance should be treated as a workload variable rather than as a special cure for flicker.


================================================================
66. ROOM LIGHTING
================================================================

A screen viewed in a completely dark room can become an extremely bright object against a dark background.

Moderate ambient lighting reduces this extreme luminance difference.

Good room lighting can therefore improve comfort without changing the display hardware.

Avoid placing strong lamps or windows where they create distracting reflections on the screen.


================================================================
67. LOWEST-REGRET DISPLAY TARGET
================================================================

If temporal sensitivity is suspected, look for evidence of LOW OR WELL-CONTROLLED PWM.

If FRC is a concern, investigate whether the panel is NATIVE 8-BIT rather than assuming a "10-bit" label means native 10-bit.

Choose a response time that provides clear text during scrolling without deliberately seeking extremely slow pixels.

Choose brightness that is comfortable in the actual room.

Choose moderate local contrast instead of maximizing contrast everywhere.

Consider a semi-gloss or lightly matte surface if strong AG sparkle is visible.

Consider hardware low-blue-light implementations when spectral discomfort appears relevant.

Treat OLED, IPS, VA, TN, W-LED, and CCFL as TECHNOLOGIES WITH DIFFERENT TRADE-OFFS rather than automatic comfort rankings.


================================================================
68. PRACTICAL SETTINGS TO TRY
================================================================

Start with moderate brightness rather than maximum brightness.

Avoid using extremely bright white text on pure black if softer contrast feels better.

Try light gray text on charcoal instead of pure white text on pure black.

Use a warmer color temperature if the default spectrum feels excessively cool.

Use Natural or sRGB modes when they produce a calmer and less saturated image.

Do not assume Natural or sRGB disables FRC.

Do not assume a low-blue-light mode disables PWM.

Treat every setting as an experiment whose result should be observed rather than assumed.


================================================================
69. THE WINDOWS DITHERING REGISTRY CLUES
================================================================

Windows graphics-driver registry areas can contain values such as:

    DitherUserMode
    DitherMode

These values may be relevant to GPU-driver dithering behavior.

Their exact meaning depends on the specific graphics driver.

Finding such a value does NOT prove that visible FRC is currently occurring.

Changing such a value can affect color processing or output behavior.

Registry changes should therefore be treated as controlled diagnostic experiments rather than universal fixes.


================================================================
70. WHY THE FINAL LIGHT OUTPUT MATTERS MOST
================================================================

The display pipeline may contain many hidden calculations.

The eye does not receive those calculations.

The eye receives light.

Therefore the most useful practical question is:

    WHAT TEMPORAL, SPECTRAL, SPATIAL, AND LUMINANCE PATTERN IS ACTUALLY REACHING THE EYE?

72. THE MOST IMPORTANT DISTINCTION
================================================================

A screen can be uncomfortable because it is TOO BRIGHT.

A screen can be uncomfortable because its LIGHT OUTPUT MODULATES.

A screen can be uncomfortable because its PIXEL VALUES MODULATE.

A screen can be uncomfortable because MOVING CONTENT IS SMEARED.

A screen can be uncomfortable because CONTRAST IS EXTREME.

A screen can be uncomfortable because the SURFACE SPARKLES.

A screen can be uncomfortable because the SPECTRUM FEELS HARSH.

A screen can be uncomfortable because TEXT IS TOO SMALL OR TOO CLOSE.

Several of these can occur simultaneously.


================================================================
73. THE FINAL MODEL FOR A 17-YEAR-OLD
================================================================

Think of the screen as a machine that converts digital information into light.

The machine can change that light in TIME through PWM.

The machine can change pixel values in TIME through FRC.

The machine can change the SPEED of those changes through pixel response characteristics.

The machine can change the INTENSITY through brightness.

The machine can change the DIFFERENCE BETWEEN EDGES through contrast.

The machine can change the COLOR MIX through its spectrum.

The machine can change the SURFACE IMAGE through its anti-glare coating.

Your eyes and brain then have to turn all of that light back into a stable picture.

If the optical input is clean and comfortable, the visual system has less unnecessary work.

If the input contains excessive brightness, distracting temporal modulation, strong reflections, sparkle, extreme contrast, or difficult motion, the visual workload can increase.

That does not mean one particular technology is universally harmful.

It means DISPLAY COMFORT IS THE RESULT OF THE WHOLE SYSTEM.


================================================================
THE SIMPLEST TRUTH
================================================================

Do not ask:

    "Is modern display technology bad?"

Ask:

    "WHAT IS THIS PARTICULAR DISPLAY DOING?"

Separate the problem into:

    PWM
    FRC
    PIXEL RESPONSE
    BRIGHTNESS
    CONTRAST
    SPECTRUM
    W-LED / OLED / CCFL
    SURFACE COATING
    AG SPARKLE
    INK-LIKE APPEARANCE
    MOTION
    VIEWING DISTANCE
    ROOM LIGHTING

Then test the variables one at a time.

A display does not need to be the newest, brightest, fastest, widest-gamut,
highest-contrast, or highest-bit-depth model to produce a comfortable image.

The lowest-regret target is a display whose FINAL LIGHT OUTPUT is stable,
clear, moderate in intensity, free of distracting surface artifacts,
and comfortable to the individual viewer.
